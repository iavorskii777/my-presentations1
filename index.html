Структура, содержание и визуальное оформление бизнес-презентации

Тема 4. От структуры и слайдов до корректной визуализации данных и стилей выступления.

Цель

Научиться создавать понятные и убедительные бизнес-презентации.

Инструменты

Python, pandas, Matplotlib, Seaborn, HTML.

Результат

Слайды с выводами, графиками и призывом к действию.

Структура бизнес-презентации

  • Титульный слайд.
  • Проблема и контекст.
  • Цель и предложение.
  • Решение и доказательства.
  • Выгоды, риски и план внедрения.
  • Призыв к действию.

Формула: проблема → решение → доказательство → выгода → следующий шаг.

Виды слайдов

ВидНазначение
ТитульныйПредставление темы и спикера
ПроблемныйПоказать значимость задачи
РешениеПредставить предложение
ДанныеПодтвердить тезис цифрами
КейсПоказать реальный результат
Дорожная картаОбозначить этапы и сроки
ФинальныйСформулировать вывод и CTA

Принципы оформления

Одна мысль

Один слайд раскрывает один тезис.

Заголовок-вывод

Не «Результаты», а «Время обработки сократилось на 40%».

Минимум текста

Детали объясняет спикер.

Единый стиль

Один шрифт, ограниченная палитра, единые отступы.

Типичные ошибки

  • Перегруженный текст и мелкий шрифт.
  • Несколько мыслей на одном слайде.
  • График без вывода, единиц измерения и источника.
  • Избыточные анимации и 3D-эффекты.
  • Таблицы вместо ключевых показателей.
  • Отсутствие призыва к действию.

Распространённая ошибка — более одной мысли на слайде. Источник: Правила оформления слайдов.

Практикум: подготовка данных

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

data = {
    "month": ["Янв", "Фев", "Мар", "Апр", "Май", "Июн"],
    "processing_time_before": [8.4, 8.6, 8.9, 9.2, 9.4, 9.8],
    "processing_time_after": [8.4, 8.3, 6.9, 5.8, 5.1, 4.6],
    "errors_before": [38, 41, 44, 47, 49, 52],
    "errors_after": [38, 37, 25, 18, 14, 11]
}

df = pd.DataFrame(data)

before = df["processing_time_before"].iloc[-1]
after = df["processing_time_after"].iloc[-1]
reduction = (before - after) / before

print(f"Снижение времени обработки: {reduction:.0%}")

График для слайда

plt.figure(figsize=(10, 5))

sns.lineplot(
    data=df,
    x="month",
    y="processing_time_before",
    label="До внедрения",
    marker="o"
)

sns.lineplot(
    data=df,
    x="month",
    y="processing_time_after",
    label="После внедрения",
    marker="o"
)

plt.title("Автоматизация сократила время обработки заявок")
plt.xlabel("Месяц")
plt.ylabel("Время обработки, ч.")
plt.grid(True, alpha=0.3)
plt.legend()
plt.tight_layout()
plt.show()

Финальный слайд

Рекомендация: согласовать пилотное внедрение автоматизации обработки заявок на одном подразделении.

  • Срок пилота — 4 недели.
  • Ожидаемый эффект — снижение времени обработки и числа ошибок.
  • Следующий шаг — утвердить рабочую группу и план пилота.

Финальный слайд всегда должен отвечать на вопрос: «Что делать дальше?»
